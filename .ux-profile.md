# UX profile — portfolio

Read by the VectorLab UX skills before any change to layout, colour or type.
This file is the contract; `src/styles/tokens.css` is its implementation.

## Direction

**Blueprint.** Light paper, blueprint ink, and a cool light that follows the
reader down the page. The reference is a drafting table: Tudor's actual method
was to draw the interface before anything was built, and the page's one piece
of ambient motion is a feedback loop — it answers the reader's scroll, which
is the subject of the degree he is taking.

## Theme

Light only. There is no dark variant and no theme toggle.

## Contrast target

WCAG 2.1 **AA** (4.5:1 body text, 3:1 non-text UI boundaries). Measured, not
estimated. The binding case is not plain text on paper but text sitting under
the brightest part of the scroll light: muted text there measures 5.40:1. Any
change to the light's opacity or tint must be re-measured against that case,
not against the flat background.

## Colour

60-30-10 by viewport area: canvas 60%, raised panels 30%, accent ~10%.
Single accent hue (blueprint blue `--text-accent`), used only on links, focus
rings, primary actions and active state. Never as a background fill.

Elevation: 1px `--border-subtle` first, then a soft shadow under 0.08 alpha.
On paper the canvas-to-panel lightness step is only 1.09:1, so the border does
the real work and the shadow only confirms it.

## Type

IBM Plex Sans throughout. IBM Plex Mono **only for real figures** — years,
metrics, measured values. Never for labels, eyebrows or decoration.

Weights 400 / 500 / 600. Never 700 or above. Hierarchy comes from size and
spacing, not weight.

## Banned (extends anti-slop)

- The default SaaS blue (`#2563EB` and neighbours). It measures 4.73:1 on this
  paper — AA by a hair and unusable on any larger area — and it is the single
  most templated choice available for a developer portfolio.
- Warm cream backgrounds near `#F4F1EA`, the other generated-page default.
- Identical rounded cards with the same grey shadow everywhere, and gradient
  washes used as decoration rather than as the light.
- ALL-CAPS tracked-out eyebrow labels above headings.
- Meta strings joined with middle dots (`A · B · C`).
- A trailing `→` appended to link or button text.
- Monospace used for small labels rather than for figures.
- `backdrop-filter` glassmorphism, multi-hue gradients on buttons, decorative
  pills around static metadata, cartoon illustrations in empty states.
- Fade-and-slide-up entrance animations on every section.

## Motion

Two moving things, both earned: the scroll light, and the badge. Everything
else is still. Only `opacity` and `transform` animate — transform is the one
property the compositor handles without re-running layout, which is why the
light is translated rather than repositioned.

`prefers-reduced-motion` removes motion rather than slowing it: the light stays
but stops following, and the badge's simulation never starts. Scroll-linked
background animation is decorative only and never applied to project work.

## Non-negotiable

The site must render completely with JavaScript disabled.
