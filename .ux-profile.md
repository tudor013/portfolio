# UX profile — portfolio

Read by the VectorLab UX skills before any change to layout, colour or type.
This file is the contract; `src/styles/tokens.css` is its implementation.

## Direction

**Control Surface.** The page should read like a well-made instrument — a
reading taken from a real system, not a SaaS dashboard. The subject is a
developer drawn to systems whose behaviour emerges from interacting parts
(agent-based market simulation, robotics, PV/battery telemetry), studying
cybernetics. Restraint is the point; one element carries the boldness.

## Theme

Dark only. There is no light variant and no theme toggle.

## Contrast target

WCAG 2.1 **AA** (4.5:1 body text, 3:1 non-text UI boundaries). Measured, not
estimated — worst current text pair is muted-on-raised at 5.10:1.

## Colour

60-30-10 by viewport area: canvas 60%, raised panels 30%, accent ~10%.
Single accent hue (amber `--text-accent`), used only on links, focus rings,
primary actions and active state. Never as a background fill.

Elevation: 1px `--border-subtle` first, then `--edge-highlight` (a top inset
line). No outer glows, no coloured shadows.

## Type

IBM Plex Sans throughout. IBM Plex Mono **only for real figures** — years,
metrics, measured values. Never for labels, eyebrows or decoration.

Weights 400 / 500 / 600. Never 700 or above. Hierarchy comes from size and
spacing, not weight.

## Banned (extends anti-slop)

- Acid-green or vermilion accents on near-black — the generated dark-portfolio
  default this direction exists to avoid.
- Tinted near-black (`#0B0B0B`, `#111`) standing in for the canvas.
- ALL-CAPS tracked-out eyebrow labels above headings.
- Meta strings joined with middle dots (`A · B · C`).
- A trailing `→` appended to link or button text.
- Monospace used for small labels rather than for figures.
- `backdrop-filter` glassmorphism, multi-hue gradients on buttons, decorative
  pills around static metadata, cartoon illustrations in empty states.
- Fade-and-slide-up entrance animations on every section.

## Motion

One orchestrated moment on the page, not scattered effects. Only `opacity` and
`transform` animate. `prefers-reduced-motion` removes motion entirely rather
than slowing it. Scroll-linked background animation is decorative only and
never applied to presented project work.

## Non-negotiable

The site must render completely with JavaScript disabled.
